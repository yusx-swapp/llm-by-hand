# Source attribution

LLM by Hand separates **original upstream reference code**, **authored teaching material** and **project-owned execution/integration glue**.

| Component | Source / terms |
|---|---|
| Model implementations and core training utilities | Hugging Face Transformers 5.1.0, Apache-2.0 |
| SFT collation and DPO objective | Hugging Face TRL 1.1.0, Apache-2.0 |
| Browser editor | Monaco Editor 0.56.0; its original LICENSE and ThirdPartyNotices.txt are retained |
| Application and authored course tooling | Apache-2.0; see the repository LICENSE and NOTICE |

Every lesson directory includes `provenance.json` with the module, original file, version, line range and hashes. It also contains the original license and relevant copyright notice. Reference excerpts are byte-identical to the corresponding pinned installed source.

Imports, tiny CPU inputs, method-carrier classes, comparison checks, explanations, code blanks and the end-to-end training integration are provided by this project. They are not falsely attributed to the upstream reference. Documentation-generation side effects may be skipped in a method carrier; the reference file itself is not rewritten.

Reference observations are generated by executing the pinned code. Constructor parameter samples are not shown before initialization; unexecuted branches do not receive invented runtime values. Updating a source version requires reviewing the source, teaching material, fixtures and fingerprints together.

Runtime dependencies installed from `requirements.txt` remain subject to their own licenses. This repository does not redistribute pretrained model weights or external training datasets.
